# Apple Phase 1 验证清单

## 自动化验收

- 重复 Observer 通知使用最新 HealthKit 汇总替换页面状态，不做增量相加。
- 每个 HealthKit 类型独立持久化 Anchor；重启后可恢复已保存位置。
- Anchored Query 仅在成功后保存新 Anchor，失败保留旧位置并重试。
- AI Provider 不可用时，手动餐食、SwiftData、营养计算和每日评分仍可运行。
- HealthKit 不可用或部分数据缺失时，评分只使用可用分项并降低完整度。
- 删除餐食只使用本 App 保存的 HealthKit 类型与样本 UUID。

## 真机复测

1. 安装新版本后授权身体、活动、训练、睡眠与恢复读取权限。
2. 记录同步前的今日步数、能量和训练汇总，前后台切换三次，确认数值没有累加。
3. 新增一条 Apple Health 活动样本，等待 Observer 刷新，再重启 App，确认只出现一次变化。
4. 分别拒绝一个读取类型和一个营养写入类型，确认其他类型仍可展示，写入失败有明确提示。
5. 开启飞行模式并禁用所有 AI Provider，确认可手动记录餐食、计算营养和生成低完整度评分。
6. 保存一条餐食后在 Apple 健康中核对对应营养样本；从 App 删除餐食，确认只删除这些样本。
7. 升级安装覆盖已有数据库，确认历史餐食、Anchor 和样本 UUID 引用仍可读取。

真机记录应包含 App 版本、iOS 版本、设备型号、测试时间、授权组合和失败截图；不得包含 API Key 或完整健康明细。
